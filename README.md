# 1% Club Finance Assistant

A RAG-based conversational assistant trained exclusively on Sharan Hegde's
(founder of the 1% Club) financial education content — the 291-minute
masterclass plus 12 topic videos from his YouTube channel.

Ask a question about savings, investing, taxes, or insurance and get an
answer grounded in what Sharan actually teaches, with clickable, timestamped
citations back to the source video.

See `claude.md` for the full architecture and project context.
